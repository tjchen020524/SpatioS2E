# Data and artifact availability

The Git repository contains software, exact biological and gene partitions,
configuration records and validation reports. The synthetic quick start and
core tests run without downloading cohort data or model weights.

## What is supplied separately

- **Numerical Source Data and Supplementary Tables:** separate manuscript
  files, not included in this code repository. A download link will be added
  when the corresponding public record is available.
- **Raw images/counts:** obtained from the original cohort providers.
- **UNI2-h, Decima, scGPT and external benchmark artifacts:** obtained from
  their providers under their respective access and license terms. Revisions
  and checksums are recorded in `configs/manuscript/external_models.yaml`.
- **Downstream checkpoints and dense predictions:** generated by running the
  documented workflows; no hosted checkpoint download is provided here.

The [reproduction guide](reproduction.md) describes preparation, alignment and
training. The [code map](paper_code_map.md) identifies the implementation behind
each analysis. Public code availability and availability of every scientific
input are separate: full-cohort reproduction requires the external inputs above.
