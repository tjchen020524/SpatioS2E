# SpatioS2E v1.1.0

Current source version for the accompanying preprint. Preparation began on
2026-09-07, with reproducibility updates on 2026-09-13 and public-source
readiness checks on 2026-09-15.

The 2026-09-13 review follow-up adds the input-preparation CLIs, selected
manuscript workflow archive, explicit run configurations and independently
installed-wheel validation described in [the reproduction guide](../reproduction.md).
The 2026-09-15 update adds a weight-free quick start, clearer data-availability
and contribution guidance, refreshed manuscript mappings and configurable
external benchmark paths. Use a Git commit to identify the exact source until
a corresponding immutable software archive is available.

This update adds the external GeneQuery and DeepSpot-M audit workflows used in
the revised manuscript, including three-seed end-to-end GeneQuery summaries.
The core evaluation and decoder APIs are unchanged. The manuscript-to-code map
now reflects the current main and Extended Data figures.

External workflows are source-distribution scripts, not new wheel entry points.
Their tests cover synthetic inputs and shared metric/control behavior; full
GPU training and gated-checkpoint inference require separately acquired inputs.
See the external audit README for commands, input schemas and provenance.

MIT copyright remains with SpatioS2E authors. No data, third-party weights,
trained checkpoints, credentials or prediction matrices are included. The
existing v1.0.0 tag and its validation records remain unchanged.
