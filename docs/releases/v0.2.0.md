# SpatioS2E v0.2.0

Version 0.2.0 is the first publication-ready release of SpatioS2E. It packages
the model, evaluation and control implementations used for the accompanying
component-resolved analysis of gene-conditioned virtual spatial
transcriptomics.

## Highlights

- Component-resolved endpoints separate across-gene mean log-expression from
  centred within-gene spatial variation and verify the exact MSE identity.
- Fitted-target models support tissue-image, spatial-neighbourhood and frozen
  gene-representation inputs.
- Target-disjoint evaluation includes the primary factorized dot-product
  decoder, bias-free and concatenation-MLP architecture controls, and an
  exactly centred residual decoder.
- Matched gene-vector controls include dimension-matched random vectors, a
  constant vector and partition-preserving identity shuffles.
- A no-image ridge counterfactual estimates held-out-target gene means directly
  from fixed gene vectors.
- Static gene-token vectors can be extracted reproducibly from the official
  scGPT whole-human checkpoint, with checkpoint and vocabulary SHA-256
  digests recorded in the output metadata.
- Frozen manuscript contracts specify the four biological section splits,
  primary gene partitions, held-out-assay settings and external-model
  provenance used in the analyses.

## Reproducibility scope

The archive contains reusable source code, configurations, tests and exact
analysis contracts. Licensed or identifiable source data, third-party model
weights, trained checkpoints and generated predictions are not redistributed.
Instructions and provenance records identify the external inputs required to
reproduce each assay.

## Validation

The release is checked by the repository test suite and by building both a
source distribution and a platform-independent Python wheel from a clean git
tree. Python 3.10 or newer is required.
