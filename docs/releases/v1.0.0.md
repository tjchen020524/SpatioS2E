# SpatioS2E v1.0.0

Version 1.0.0 is the first stable, citable release of SpatioS2E. It packages
the model, evaluation and control implementations used in the accompanying
component-resolved analysis of gene-conditioned virtual spatial
transcriptomics.

## Supported uses

- Evaluate any aligned observed and predicted `[spot, gene]` matrices with
  gene-mean, within-gene, centred and full-matrix endpoints and verify the exact
  MSE decomposition.
- Train and evaluate target-disjoint shared decoders from precomputed tissue
  representations and fixed gene vectors, including matched vector controls,
  architecture variants and a no-image gene-mean counterfactual.
- Run the fitted-target reference workflow after obtaining the required cohort
  data and licensed external encoders or weights.
- Reuse the exact biological partitions, downstream target partitions and
  held-out-assay contract archived for the manuscript.

## External inputs

Raw or identifiable cohort data, third-party weights, trained checkpoints,
generated predictions and manuscript Source Data are distributed separately.
New-cohort prediction and full manuscript regeneration require the external
inputs identified in the documentation.

## Release contents

- Component-resolved endpoints, section-wise centring and exact MSE
  decomposition.
- Fitted-target models and a donor-disjoint hippocampus example configuration.
- Primary and architecture-audit target-disjoint decoders with reusable fitting
  and evaluation utilities.
- Dimension-matched random, constant and partition-preserving identity-shuffle
  controls.
- No-image ridge prediction of held-out-target gene means.
- Reproducible extraction of static scGPT gene-token vectors from an upstream
  checkpoint.
- Frozen four-cohort biological splits, primary and sensitivity gene
  partitions, external-model provenance and analysis hyperparameters.
- Unit, synthetic-training, packaging, lint and clean-room validation records.
